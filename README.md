Менеджер контактів
Програма для управління контактами, розроблена на Python з використанням об'єктно-орієнтованого програмування та тестів.

Основні можливості
Графічний інтерфейс: зручне вікно з таблицею та кнопками на базі tkinter.
Типи контактів: підтримка особистих і робочих контактів із різними полями.
Збереження даних: контакти автоматично записуються у файл JSON.
Перевірка вводу: перевірка правильності номерів телефонів та email.
Пошук: швидкий пошук контактів під час введення тексту.
Тестування: набір тестів для перевірки роботи програми через pytest.

Технології
Мова програмування: Python 3.12
Інтерфейс: Tkinter
Тестування: Pytest
Контроль версій: Git

Структура проєкту

main.py — основний код програми.
test_contacts.py — тести для перевірки моделей контактів та валідації.
test_storage.py — тести для збереження даних у JSON.
test_manager.py — тести для бізнес-логіки управління контактами.
requirements.txt — перелік необхідних бібліотек.
.gitignore — налаштування ігнорування тимчасових файлів та збережених даних.
README.md — документація проєкту.

Встановлення залежностей
Перед запуском тестів обов'язково встановіть необхідні бібліотеки з файлу requirements.txt за допомогою команди:
pip install -r requirements.txt

Як запустити програму?
Відкрийте термінал у папці з проєктом та виконайте команду:
python main.py

Як запустити тести?
Для перевірки роботи всіх модульних тестів виконайте:
pytest
